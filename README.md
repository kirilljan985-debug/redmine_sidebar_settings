# Настройки меню (redmine_sidebar_settings)

Плагин Redmine 7+ для управления **прикладными меню** Redmine: переименование,
скрытие и изменение порядка пунктов **мышкой**, прямо из администрирования.

Управляются три меню ядра (`Redmine::MenuManager`):

- **меню приложения** (`:application_menu`) — «Рабочее пространство» в левой
  панели ModernLayout (Действия, Задачи, Диаграмма Ганта, Agile board,
  Календарь, Новости и т.д.) вне проекта;
- **меню проекта** (`:project_menu`) — те же вкладки внутри проекта (и вкладки
  в стоковой теме);
- **верхнее меню** (`:top_menu`) — верхняя полоса в стоковой теме.

Поскольку правки вносятся на уровне ядра, их подхватывает любой layout и тема,
включая ModernLayout: его секция «Рабочее пространство» рендерится из
`:application_menu` / `:project_menu`.

Отдельно управляются **фиксированные ссылки левой панели ModernLayout**
(Домашняя страница, Моя страница, Мои задачи, Проекты, Администрирование) —
они жёстко прописаны в layout'е плагина ModernLayout, поэтому для них работает
клиентский слой плагина (те же переименование / скрытие / порядок).

Это **только отображение**: маршруты, права и страницы не трогаются, скрытый
пункт остаётся доступным по прямому URL, а вернуть его можно в тех же
настройках одной галочкой.

Совместимость: Redmine **7.0+** (CI: `7.0-stable` и `master`).

## Установка

```bash
cd /путь/к/redmine/plugins
git clone https://github.com/kirilljan985-debug/redmine_sidebar_settings.git
```

и перезапуск Redmine. Миграций и гемов нет.

## Использование

**Администрирование → Настройки меню** (пункт с иконкой в сетке
администрирования). Страница показывает группы меню; в каждой — фактические
пункты в текущем порядке, включая добавленные другими плагинами; новые пункты
появляются автоматически.

- **Порядок** — перетащите строку мышкой (или стрелками ↑/↓).
- **Подпись** — правьте текст в поле; очистка поля возвращает стандартное
  название.
- **«скрыта»** — убирает пункт из меню; пункт остаётся в списке — снимите
  галочку, чтобы вернуть его (без перезапуска).
- **Сохранить** — применяется сразу.

Серверные меню применяются при каждом старте Redmine (после регистрации меню
всех плагинов) и сразу при сохранении; в multi-worker развёртываниях остальные
worker'ы подхватят изменения после рестарта. Конфигурация фиксированных ссылок
ModernLayout применяется на стороне браузера на каждой странице.

Группа «Левая панель ModernLayout» редактируется по каталогу известных ссылок
(их пять, пути стабильны). Список «ПРОЕКТЫ» в панели — динамический список
проектов, это не меню.

## Разработка и тесты

```bash
bundle exec rake redmine:plugins:test NAME=redmine_sidebar_settings RAILS_ENV=test
```

CI (GitHub Actions): матрица Redmine `7.0-stable` / `master`, sqlite,
eager-load smoke check. Локальные проверки: `ruby -c`, `node --check`,
standalone minitest для чистой логики (`lib/.../config.rb`).
