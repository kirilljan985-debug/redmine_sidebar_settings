# Настройки меню (redmine_sidebar_settings)

Плагин Redmine 7+ для управления **прикладным меню приложения** (то, что в
стоковом Redmine — верхнее меню `:top_menu`, а в layout'ах вроде ModernLayout —
левая навигационная панель): переименование, скрытие и изменение порядка
пунктов **мышкой**, прямо из администрирования.

Работает на уровне ядра (`Redmine::MenuManager`), поэтому конфигурацию
подхватывает любой layout и тема — включая ModernLayout. Это **только
отображение**: маршруты, права и страницы не трогаются, скрытый пункт остаётся
доступным по прямому URL, а вернуть его можно в тех же настройках одной
галочкой.

Совместимость: Redmine **7.0+** (CI: `7.0-stable` и `master`).

## Установка

```bash
cd /путь/к/redmine/plugins
git clone https://github.com/kirilljan985-debug/redmine_sidebar_settings.git
```

и перезапуск Redmine. Миграций и гемов нет.

## Использование

**Администрирование → Настройки меню** (пункт с иконкой в сетке
администрирования).

- Список показывает **фактические пункты меню** в текущем порядке — включая
  добавленные другими плагинами; новые пункты появляются автоматически.
- **Порядок** — перетащите строку мышкой (или стрелками ↑/↓).
- **Подпись** — правьте текст в поле; очистка поля возвращает стандартное
  название.
- **«скрыта»** — убирает пункт из меню; пункт остаётся в списке отмеченным —
  снимите галочку, чтобы вернуть его (без перезапуска).
- **Сохранить** — применяет сразу.

Правила каскадирования нет: конфигурация описывает итоговое состояние меню
(полный порядок, подписи, скрытые пункты). Пункты, не упомянутые в `order`,
идут после перечисленных в их текущем порядке; новые пункты плагинов
добавляются в конец автоматически.

Конфигурация хранится в JSON (свернутый блок «JSON» под редактором
синхронизирован с формой) и применяется:
- при каждом старте Redmine (после регистрации меню всех плагинов);
- сразу при сохранении в админке.

В multi-worker развёртываниях остальные worker'ы подхватят изменения после
перезапуска (стандартное ограничение in-memory меню ядра).

## Ограничения

- Управляется именно меню приложения (`:top_menu`). Список «ПРОЕКТЫ» в
  layout'ах — это динамический список проектов, не пункт меню.
- Скрытие — отображение, а не права доступа.
- Подписи-переименования статичны: если стандартная подпись зависит от
  локали пользователя, переименованный пункт покажет заданный текст всем.

## Разработка и тесты

```bash
bundle exec rake redmine:plugins:test NAME=redmine_sidebar_settings RAILS_ENV=test
```

CI (GitHub Actions): матрица Redmine `7.0-stable` / `master`, sqlite,
eager-load smoke check. Локальные проверки: `ruby -c`, `node --check`,
standalone minitest для чистой логики (`lib/.../config.rb`).
